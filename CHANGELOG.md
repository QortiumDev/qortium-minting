# Changelog

## 1.4.1 - 2026-07-16

- Reworked the app into My Minting, Minters, Blocks, and Developers workspaces.
- Added selected-account management, real write confirmation tracking, the full
  minting-group roster, identity avatars, multi-column sorting, and progressive
  account enrichment.
- Added Previewnet batch-aware block filtering, expandable online-account
  snapshots, the current online-minter table, and visibility-aware smart refresh.
- Added Classic, Modern, and Fun style support with bundled local fonts and
  responsive table/layout behavior.
- Added the sandbox-safe clipboard fallback already used by Polls.
- Expanded protocol documentation and focused tests for batch boundaries,
  identity-request chunking, sorting, refresh planning, and pending actions.
